
# 自由規劃實驗架構

目前流程：使用者目標 → 相機確認任務初始桌面 → 高階 LLM 自行拆解 → 低階 LLM 自然語言操作計畫 → C# 確定性自然語言 adapter → 執行前檢查 → 模擬驗證（2D：Unity；3D：URSim＋Isaac Sim；畫面重疊率＋LLM 看模擬畫面）→ UR3e。相機只在任務開始拍一次，執行後不再觀測驗證（2026-10-08 起，三個版本相同；之前是執行後局部與整體觀測驗證）。

未達標時由 LLM 生成失敗摘要及暫定規則，逐輪累積寫入下一輪 system prompt；最多十次，反思判定目標在物理上不可能時提早結束。每個任務以收到指令時的桌面為起點（FIXED_BASELINE=1 則任務間恢復固定初始積木配置），任務內保留所有實際操作結果；2026-10-08 起每輪都用任務開始時的觀測（驗證沒過時手臂沒動，手臂執行失敗則任務結束）。規則不跨任務沿用。

主程式不再使用固定任務路由、bitmap 模板、確定性布局或派工。（2026-10-02 起重新加入雙模型設計目標 bitmap，2026-10-07 起由 LLM 先判斷平面或立體、立體畫高度圖，見 experiment_protocol.md；規劃的 LLM 仍只輸出自然語言，布局仍由它決定。）機器底層保留既有函式介面、運動學、碰撞與硬體檢查。模型只輸出自然語言，不接收或填寫 JSON schema；C# adapter 只把自然語言中已明確決定的來源、數值目標與函式轉成 Unity 的內部 JSON 通訊格式。

詳見 [實驗協定](experiment_protocol.md)。
