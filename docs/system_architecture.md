
# 自由規劃實驗架構

目前流程：使用者目標 → 相機確認任務初始桌面 → 高階 LLM 自行拆解 → 低階 LLM 自然語言操作計畫 → 忠實轉譯器 → 執行前檢查 → Unity／UR3e → 局部與整體觀測驗證。

未達標時由 LLM 生成失敗摘要及暫定規則，寫入下一輪 system prompt；最多十次。任務間恢復固定初始積木配置，任務內保留所有實際操作結果並重新觀測。規則不跨任務沿用。

主程式不再使用固定任務路由、bitmap 模板、確定性布局或派工。機器底層保留既有函式介面、運動學、碰撞與硬體檢查。規劃文字不受 JSON schema 限制；JSON 僅用於轉譯和內部執行通訊。

詳見 [實驗協定](experiment_protocol.md)。
